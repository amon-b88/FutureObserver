# 观察者论坛 Observer Forum（原 Future Observer）v0.4.0

SillyTavern UI Extension.

把当前聊天最近若干楼放到你选择的时间方向（过去 / 现在 / 未来）去观察，在不写入主线聊天的情况下生成一段与主线分离的评论、吐槽和争论。

通过 SillyTavern 的"从 Git URL 安装扩展"安装。

安装并启用后，在扩展设置中找到"🔭 观察者论坛"，或者点击屏幕上可拖动的 🔭 悬浮球快捷生成。

生成使用 SillyTavern 的 quiet generation（或你自己配置的自定义API），因此不会作为新消息写入当前聊天。

## v0.4.0 更新内容

### 时间方向 + 身份视角

不再是单一的"未来观测"，现在分三个时间方向，每个方向下有对应的评论者身份可选：

- **过去**：更早以前的当事人们互相议论吐槽 / 过去的路人网友（认知落差产生的各种反应，不限于"天罚"一种解读）
- **现在**：当事人当场实时辩解争吵 / 同时代路人网友实时吃瓜
- **未来**：未来网友 / 历史学者 / 当事人后代 / 未来新闻 / 当事人多年后回忆翻案
- 每个方向都保留"混合模式"

### 楼中楼跟帖

生成结果里，部分评论会随机带上 1~2 条"跟帖"回复，模拟真实论坛热门楼层有人接话吵、冷门楼层没人理的自然感，不是每条评论都有人回。

### 自定义API

可以在设置里单独配置一个 API 端点（OpenAI 兼容格式）+ 密钥 + 模型名称，跑观察者论坛时用这个便宜模型，不占用/不影响你酒馆主线聊天用的那个（更贵的）API。

⚠️ 注意：密钥是明文存在插件设置里的，不是酒馆官方推荐的加密存储方式，请不要把设置文件/设置截图分享给别人。

### 悬浮球

屏幕上的可拖动 🔭 悬浮球，单击展开小面板直接生成、查看结果，不用每次都打开扩展设置抽屉。位置会自动记住，设置里可以关闭。

## v0.5.0 更新内容

- **异世界**：新增第四个时间方向，下面两个子模式——随机称号模式（AI现编中二称号发言）、同人模式（模仿其他作品角色的人设点评，网名+括号真实姓名，格式如"疾风影帝（漩涡鸣人）"）。同人模式可以在悬浮球弹窗里填作品名（如"火影忍者"），留空则AI自由选择
- **弹窗放大/复位**：悬浮球弹窗标题栏新增放大按钮，尺寸和位置状态会跨会话记住；双击悬浮球可以把弹窗位置和大小一键复位
- **弹窗可独立拖动**：按住弹窗标题栏可以把整个面板拖到任意位置，跟悬浮球本身的位置分开记
- 楼中楼跟帖的识别规则放宽了一些，减少"跟帖显示成普通楼层"的情况（不保证100%准确，AI输出格式有随机性）
