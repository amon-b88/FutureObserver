# 观察者论坛 Observer Forum（原 Future Observer）v0.4.0

SillyTavern UI Extension.

把当前聊天最近若干楼放到你选择的时间方向（过去 / 现在 / 未来）去观察，在不写入主线聊天的情况下生成一段与主线分离的评论、吐槽和争论。

通过 SillyTavern 的"从 Git URL 安装扩展"安装。

安装并启用后，在扩展设置中找到"🔭 观察者论坛"，或者点击屏幕上可拖动的 🔭 悬浮球快捷生成。

生成使用 SillyTavern 的 quiet generation（或你自己配置的自定义API），因此不会作为新消息写入当前聊天。

## v0.4.0 更新内容

### 时间方向 + 身份视角

不再是单一的"未来观测"，现在分三个时间方向，每个方向下有对应的评论者身份可选：

- **过去**：更早以前的当事人们互相议论吐槽 / 过去的路人网友（认知落差产生的各种反应，不限于"天罚"一种解读）
- **现在**：当事人当场实时辩解争吵 / 同时代路人网友实时吃瓜
- **未来**：未来网友 / 历史学者 / 当事人后代 / 未来新闻 / 当事人多年后回忆翻案
- 每个方向都保留"混合模式"

### 楼中楼跟帖

生成结果里，部分评论会随机带上 1~2 条"跟帖"回复，模拟真实论坛热门楼层有人接话吵、冷门楼层没人理的自然感，不是每条评论都有人回。

### 自定义API

可以在设置里单独配置一个 API 端点（OpenAI 兼容格式）+ 密钥 + 模型名称，跑观察者论坛时用这个便宜模型，不占用/不影响你酒馆主线聊天用的那个（更贵的）API。

⚠️ 注意：密钥是明文存在插件设置里的，不是酒馆官方推荐的加密存储方式，请不要把设置文件/设置截图分享给别人。

### 悬浮球

屏幕上的可拖动 🔭 悬浮球，单击展开小面板直接生成、查看结果，不用每次都打开扩展设置抽屉。位置会自动记住，设置里可以关闭。

## v0.5.0 更新内容

- **异世界**：新增第四个时间方向，下面两个子模式——随机称号模式（AI现编中二称号发言）、同人模式（模仿其他作品角色的人设点评，网名+括号真实姓名，格式如"疾风影帝（漩涡鸣人）"）。同人模式可以在悬浮球弹窗里填作品名（如"火影忍者"），留空则AI自由选择
- **弹窗放大/复位**：悬浮球弹窗标题栏新增放大按钮，尺寸和位置状态会跨会话记住；双击悬浮球可以把弹窗位置和大小一键复位
- **弹窗可独立拖动**：按住弹窗标题栏可以把整个面板拖到任意位置，跟悬浮球本身的位置分开记
- 楼中楼跟帖的识别规则放宽了一些，减少"跟帖显示成普通楼层"的情况（不保证100%准确，AI输出格式有随机性）

## v0.6.0 更新内容

- **弹窗按时间方向变色**：过去=复古黄褐、现在=中性绿灰、未来=科幻蓝、异世界=紫，选哪个方向弹窗基调跟着换
- **随机长度**：每次生成的楼层数量和每条字数不再是固定的"6~8条/20~80字"，改成每次随机抽一组范围，热闹程度和详细程度会有变化
- **同人模式新增"世界错觉"**：同人模式下有一定概率会有某位角色产生错觉，怀疑剧情正发生在自己所在的世界，情绪会明显更激烈，跟其他角色的轻松围观形成反差

## v0.7.0 更新内容

- **"世界错觉"改为代码真随机8%**：不再靠AI自己判断概率，插件生成前会先真的掷一次骰子（命中率固定8%），命中才会把这条规则加进prompt；命中时还会从几种不同的"由头"里随机挑一种，避免每次都是同一套措辞
- **世界书接入**：会读取当前聊天关键词命中的世界书内容，作为背景参考一起交给AI（不是整本世界书，只是酒馆本身按关键词触发出来的那部分）。设置里新增"包含世界书设定"开关，可以关掉

## v0.8.0 更新内容

- **微博体**：悬浮球弹窗里新增开关，开启后会先由某位评论者发一条标题党风格的"主贴"，之后所有楼层评论都围绕主贴的具体观点展开，而不是各说各话。主贴在结果区会渲染成醒目的卡片，跟普通楼层区分开。这个开关跟"时间方向/身份"是完全独立、可以任意组合的
- **记忆开关**：悬浮球弹窗里新增开关，开启后这次生成会参考"同一类评论者"上一次讨论的内容（继续吵、和解、翻篇都由AI自己判断）。记忆按"时间方向+身份+（同人模式下）具体作品名"分开存，绑定在当前这个聊天/角色身上，不会跨故事串线，目前只记最近一次

## v0.9.0 更新内容

- **历史记录浏览**：结果区上方新增"◀ 上一条 / 第X条 / 下一条 ▶"导航，能翻看同一分类（时间方向+身份+同人模式下的具体作品名）最近生成过的几次结果（最多保留5条，超过自动丢弃最旧的）。跟"记忆开关"是两回事——历史浏览不管记忆开关开没开，每次生成都会记；记忆开关管的是"AI要不要看上一次内容"。同样绑定在当前聊天上

## v0.9.1 修复

- 修复"微博体"和"记住上一次"两个勾选框事件绑定时机错误导致设置无法真正保存的bug——之前勾选之后关闭再打开弹窗，勾选会被自动清空，内部设置其实从未生效

## v0.9.2 修复

- 修复"记住上一次"生成时容易变成"把上次内容换几个词重发一遍"的问题——把给AI的指令改得更明确强硬，要求必须体现"时间往后推进了"，而不是原地复述上次的论点

## v0.10.0 更新内容

- **只读AI发言**：设置抽屉里新增开关，打开后"读取最近N楼"精确指最近N条AI角色写的内容，不含你自己发的消息（往前扫聊天记录凑够N条AI发言为止，而不是N条里混着用户消息再从中筛选）
- 楼层数上限从50调到100（实际能读多远，还是受"最多读取字符数"这个设置联合限制，两个要一起调才有意义）

## v0.11.0 更新内容

- **同人模式新增"剧情本身就发生在这部作品的世界里"开关**：专治穿越卡/无限流场景的割裂感——之前同人角色一律被当成"围观别的故事"的局外人写，导致鬼杀队对"竟然有鬼"这种自己世界的基本常识表现得像看新闻一样震惊。勾上这个开关后，评论者会被当成这个世界真实的当地人来写，不会对本该熟悉的设定大惊小怪，且会结合原作信息，把剧情当成"发生在自己身边的真事"来反应。这个勾选框只在"异世界·同人模式"下出现，跟作品名输入框在同一个位置

## v0.12.0 更新内容

- **采纳到正文**：同人模式下，每条评论/跟帖后面会出现一个"📥 采纳"按钮，点一下会把这条内容转换成 `/sendas name="真实姓名" 台词内容` 的格式，自动填进酒馆自己的正文输入框——不会自动发送，你看一眼、需要的话自己编辑，确认没问题了自己点发送。转换是纯格式清洗（去掉楼层编号、网名、括号），不额外调用AI，免费、瞬间完成。这个按钮只在同人模式下出现，因为需要"网名（真实姓名）"这个格式才能提取出角色名
- 同人模式新增规则：评论者提到"要来帮忙/送东西"这类内容时，力度要匹配角色在原作里的真实身份地位，避免出现不符身份的离谱赠礼，也要考虑别打破当前剧情的强度平衡

## v0.13.0 更新内容

- **一键重置选项**：悬浮球弹窗里新增"↺ 重置选项"按钮，一键清空作品名、"剧情发生在自己世界"勾选、微博体、记忆这四项，不用一个个手动取消
- **作品名历史记录**：作品名输入框旁边新增一个"▾"箭头，点开能看到最近填过的作品名（最多记8个），点一下直接选用，不用重新打字

## v0.14.0 更新内容

- **自动获取可用模型列表**：自定义API设置里，模型名称旁边新增"🔄 获取列表"按钮。填好端点URL和API密钥后点一下，插件会向该服务查询有哪些可用模型，并在下方出现"可选模型"下拉框，选一个就自动填进模型名称，不用自己手打。列表会保存下来，刷新页面后还在。仍然可以手动输入模型名称（比如服务不支持查询列表时）

## v0.14.1 修复

- **忽略末尾选项区**：设置抽屉里新增开关（默认开启）。读取聊天时，会先把每一楼里 `<action>…</action>` 包起来的待选项（`[Opt1:😇]` 这类）删掉再交给AI，评论者不会再去评论你根本没选的备选剧情。即使选项区没写结束标签、或者没有标签只剩 `[Opt数字:…]` 单独成行，也会被删掉

## v0.15.0 更新内容（界面与输出大改）

- **固定输出格式，楼中楼不再认错**：提示词现在要求AI按 `楼|编号|网名|内容` / `回|编号|被回复的编号|网名|内容` 输出，程序只认这几种行。跟帖明确知道回复的是哪一楼，会挂在那一楼下面的小框里；开场白、分隔线、乱入的标签一律丢弃，不会再出现无意义的空格子。AI没按格式写时，仍会尝试识别旧格式，实在认不出才逐行显示
- **全新界面**：去掉头像，楼层卡片只留网名和楼层号；跟帖放在被回复楼层下面的浅色小框里；微博体的主贴做成醒目的顶部卡片；配色继续跟着时间方向变（设置抽屉里也一样）
- **折叠式弹窗**：弹窗顶部常驻"时间方向 + 身份 + ⚙"一行，其余选项（作品名、微博体、记忆、内容量等）收进 ⚙ 面板，折叠时用小标签显示当前开了哪些；点"生成"会自动折叠。"生成评论区"按钮固定在弹窗底部
- **手机适配**：窄屏（宽度不超过640px）下弹窗自动变成铺满屏幕约九成高度的底部抽屉，高度改用 `dvh`，不再被浏览器地址栏遮住
- **内容更充实**：
  - 新增"内容量"四档（精简/标准/丰富/长篇），默认"丰富"，决定楼层数、跟帖数和每条字数，且字数有长有短、有明显起伏
  - 每次生成由代码随机抽几个"讨论焦点"和"说话风格"交给AI，避免每次都走同一套模板
  - 加入反八股规则：要抓具体细节、不要三段式、不要金句收尾、同一口头禅最多两次、评论者之间要互动
  - 新增"先构思再写"开关（默认开）：AI先在 `<构思>` 里列思路和评论者人设，再写正文；构思部分会被程序自动删掉
  - 新增"最大输出长度"设置：自定义API走 `max_tokens`，酒馆主连接走 `responseLength`，填0=不指定
